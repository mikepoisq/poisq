# Серверная конфигурация Poisq.com

## Версии компонентов

| Компонент   | Версия        |
|-------------|---------------|
| PHP         | 8.3.30        |
| MariaDB     | 11.4.10       |
| Meilisearch | 1.40.0        |
| HestiaCP    | 1.9.4         |
| OS          | Debian/Ubuntu |

## Архитектура

```
Браузер → Nginx (80/443) → Apache (8080/8443) → PHP-FPM
```

- **Nginx** — принимает запросы, отдаёт статику (CSS/JS/картинки) с `expires max`
- **Apache** — промежуточный прокси, обрабатывает PHP-запросы
- **PHP-FPM** — выполняет PHP-код
- Кастомные Nginx-правила: `/home/mike/conf/web/poisq.com/nginx.conf_poisq` и `nginx.ssl.conf_poisq`
- Основные конфиги Nginx управляются HestiaCP — **не редактировать напрямую**

## PHP-FPM пул

**Файл:** `/etc/php/8.3/fpm/pool.d/www.conf`

| Параметр                 | Было         | Стало      | Зачем                                             |
|--------------------------|--------------|------------|---------------------------------------------------|
| `pm`                     | `ondemand`   | `dynamic`  | Воркеры всегда готовы, нет задержки на запуск     |
| `pm.max_children`        | `4`          | `8`        | Вдвое больше параллельных PHP-запросов            |
| `pm.start_servers`       | —            | `2`        | 2 воркера стартуют вместе с FPM                  |
| `pm.min_spare_servers`   | —            | `2`        | Минимум 2 тёплых воркера всегда ждут запросов    |
| `pm.max_spare_servers`   | —            | `4`        | Не более 4 простаивающих одновременно             |
| `pm.max_requests`        | `4000`       | `500`      | Частый рестарт воркеров — защита от утечек памяти |
| `pm.process_idle_timeout`| `10s`        | `10s`      | Без изменений                                     |

Расчёт памяти: 8 воркеров × ~50 MB = ~400 MB максимум. Сервер: 3.8 GB RAM, ~1.7 GB доступно.

Перезагрузка без даунтайма: `systemctl reload php8.3-fpm`

## APCu кеш

Включён в PHP-FPM (в CLI выключен — это норма).
Размер: **32 MB** (`apc.shm_size`).

| Ключ                      | Содержимое                              | TTL    | Файл               |
|---------------------------|-----------------------------------------|--------|--------------------|
| `poisq_all_cities`        | Все ~800 городов из таблицы `cities`    | 1 час  | `results.php`      |
| `poisq_countries_list`    | Список стран для разбора текста запроса | 1 час  | `results.php`      |
| `poisq_js_countries`      | Список стран для модалки выбора страны  | 1 час  | `index.php`        |

Сброс кеша при необходимости: `systemctl restart php8.3-fpm`
